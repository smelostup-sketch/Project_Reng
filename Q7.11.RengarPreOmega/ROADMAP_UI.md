# ДОРОЖНАЯ КАРТА ИНТЕРФЕЙСА (UI ROADMAP) — Project_Rengar
Запрос заказчика: (1) внутриигровая панель настроек, (2) визуально привлекательная
обёртка в стиле League of Legends (фирменные линии, частицы, цвета) + список нужных ассетов.
Принципы: компонентность, data-driven (никакого хардкода), каждая фаза проверяема
headless-стендами; визуал — LIVE-чек заказчика.

## 0. ДНК стиля (LoL / Hextech) — референс для всех фаз
- Палитра: фон `#010A13`/`#0A1428` (глубокий сине-чёрный), золото `#C8AA6E`,
  светлое золото `#F0E6D2`, бронза `#C89B3C`, хек-магия `#0AC8B9`/`#0397AB`,
  акцент урона `#BE1E37`.
- Линии: тонкие золотые рамки с угловыми расширениями и «огранкой» (скошенные углы,
  ромбы на стыках), лёгкое внутреннее свечение у активных элементов.
- Материалы: тёмный полупрозрачный пергамент/стекло под панелями, золото — металл.
- Типографика: засеченный display-шрифт для заголовков + нейтральный для текста.
  **Обязательна кириллица** (UI русский): кандидаты — Playfair Display (кириллица есть),
  PT Serif, Cormorant; для цифр/технического текста — Inter/Roboto.
- Частицы: золотая пыль на hover/confirm, бирюзовое свечение магии на ульте,
  искры при успешном блоке (свяжется с L4 чек-листа блока).

## 1. Архитектура настроек (сквозная, без задвоения)
- **SettingsService (autoload, единственный владелец)**: реестр настроек — данные
  (Dictionary/Resource: id, тип, границы, default, путь привязки), сохранение в
  `user://settings.cfg` (ConfigFile), сигнал `setting_changed(id, value)`.
  Значения применяются к СУЩЕСТВУЮЩИМ экспортам узлов (привязки, не копии):
  | Настройка | Цель привязки (уже в проекте) |
  |---|---|
  | Чувствительность мыши | `ThirdPersonCamera.mouse_sens` |
  | Дистанция камеры | `ThirdPersonCamera.distance` (min/max уже есть) |
  | Инверсия камеры | новое поле камеры (1 строка) |
  | Громкость master/SFX | AudioServer-шины (создать в project.godot: Master/SFX/UI) |
  | Полноэкранный/разрешение/vsync | DisplayServer (стандарт Godot) |
  | Debug-логирование | `CombatComponent.debug_logging/verbose_logging` (оба узла) |
  | Debug хитбоксов (F8) / лучи (F3) | `CombatComponent.debug_hitboxes_enabled`, `CombatDebugVisualizer` |
  | Раздел «Разработка» (скрыт по умолчанию) | калибровки: `block_activation_time`, `block_active_duration`, `attack_animation_speed` игрока, `leap_*` — только чтение/запись через тот же реестр |
- **SettingsPanel (сцена Control)**: строится из реестра (data-driven: строка UI =
  тип настройки: slider/toggle/dropdown/keybind), ничего не знает о конкретных id.
- **PauseMenu (CanvasLayer, process_mode=ALWAYS)**: ESC → Продолжить/Настройки/Выйти;
  `get_tree().paused` — у существующих узлов process_mode по умолчанию (паузятся).
- Проверка headless: стенд `sim_settings.gd` — загрузка cfg, round-trip значений,
  применение к привязкам, инверсия/границы; структурные проверки панели (построение
  строк из реестра).

## 2. Фазы
**P1 — Сервис настроек + ESC-меню (ассеты НЕ нужны, всё programmatic).**
StyleBoxFlat: тёмный фон #0A1428 (альфа 0.92), золотая рамка 2px #C8AA6E, скошенные
углы имитируются NinePatch без текстур либо Polygon2D-подложкой. Дефолтный шрифт Godot
(кириллица есть). Итог: полностью работающие настройки в игре. Оценка: LIVE + sim_settings.
**P2 — Обёртка HUD (ассеты НЕ нужны, улучшается по мере поступления).**
Рамка HP-бара (PlayerUI уже в группе player_ui), пики стаков (3 золотых + фиолетовый —
StacksComponent уже эмитит stacks_updated), свечение «ульта готова», ИНДИКАТОР БЛОКА
(прямо сейчас блок невидим — L4 чек-листа: иконка/дуга направления блока у курсора или
под игроком). Итог: боевой HUD читается без арт-ассетов.
**P3 — Hextech-скин (нужны ассеты раздела 3, позиции 1–3, 5).**
Замена programmatic-подложек на 9-slice текстуры рамок/кнопок, шрифт, фон-пергамент.
**P4 — Частицы, звук, курсор (нужны ассеты 4, 6, 7).**
GPUParticles2D: золотая пыль (hover/confirm), бирюза (ульта), искры (блок-успех —
сигнал `block_successful` уже есть); UI-звуки на шину UI; кастомный курсор.
**P5 — Главное меню (опционально, после P3–P4).** Титул, кнопки, фон-арт (позиция 8).

## 3. Список ассетов («какие нужны») — по позициям
1. **9-slice рамки панелей/окон**: PNG 384×384 (углы+срезы), 2–3 варианта (панель,
   подпанель, tooltip), прозрачность, золотая огранка. Godot: NinePatchRect.
2. **Кнопки**: 9-slice 4 состояний (normal/hover/pressed/disabled) × 2 формы
   (основная/вторичная), PNG 256×64 каждое.
3. **Шрифты**: display-засеченный с кириллицей (woff2/ttf/otf) + текстовый; 2 начертания.
4. **Иконки** (SVG или PNG 128×128, золото-линейные на прозрачном): настройки (шестерня),
   звук, видео, управление, назад/выход; боевые: стрелки направлений ←/↑/→ (для телеграфа
   и индикатора блока — пункт B отчёта блока!), щит (блок), золотой/фиолетовый пики стаков,
   иконка ульты Ренгара.
5. **Текстуры-подложки**: пергамент/шум тёмный (tileable 512×512), золотые разделители
   (полосы 512×32), угловые flourishes (256×256).
6. **Частицы**: sprite-sheet золотой пыли (например 8×8 кадров 64×64), мягкий glow-спрайт
   (radial 128×128), искра блока. Либо генерим процедурно (GradientTexture2D) — P4 без закупок.
7. **UI-звуки**: hover/press/confirm/back/открытие панели (WAV/OGG, ≤0.5с каждый, 5 шт.).
8. **Фон главного меню (P5)**: арт 1920×1080 (Ренгар-стилистика; позже — сцена/локация).
Источники: (а) пакеты itch.io/AssetStore «fantasy gold UI» (проверять лицензию и кириллицу);
(б) заказ у художника по этому списку; (в) **официальные ассеты Riot использовать нельзя
в коммерческом проекте** — фан-политика Riot разрешает некоммерческое фан-творчество,
стилизацию «в духе» — да, прямые их текстуры/шрифты (Beaufort for LOL и т.п.) — нет;
(г) черновики могу сгенерировать image-моделью (рамки/иконки/фон) — как референс для (а)/(б).

## 4. Ограничения и проверки
- Контейнер headless без GPU: визуал каждой фазы — LIVE-скрин заказчика; структура —
  headless-стенды (загрузка сцен, реестр, привязки, сигналы). Скриншот-автоматизацию
  можно поднять через Movie Maker mode, если понадобится (отдельная задача).
- Порядок: P1 и P2 не зависят от ассетов и от исхода боя с блоком (опции A–C отчёта) —
  можно параллелить; P3–P4 ждут ассеты; телеграф-стрелки (иконка 4) усиливают и бой.

## 5. Ответ на стратегический вопрос заказчика (бутылочное горлышко)
Согласен частично: кастомные анимации/модели — потолок КАЧЕСТВА стиля, но не условие продолжения:
- **Анимация блока**: Mixamo (тот же риг Y Bot, бесплатно) содержит клипы блока/щита
  (ищем: "Block", "Shield Block", "Blocking Idle") — L4 закрывается без кастом-артиста;
  интеграция = MixamoAnimationLibrary + один экспорт клипа (паттерн уже есть).
- **ИИ (очередь п.3)**: калибруется по ЧИСЛАМ (окна, бюджеты, телеграфы — sim_block_timing
  уже даёт метрики) независимо от наличия анимаций; визуал — слой поверх контракта.
- **Локации/частицы/UI**: P1–P2 UI и процедурные частицы — без закупок; локации — из
  имеющихся текстур (grass/bush) + процедурное.
Вывод: ближайшая разработка НЕ блокирована; кастом-арт — плановый апгрейд стиля (P3+).
